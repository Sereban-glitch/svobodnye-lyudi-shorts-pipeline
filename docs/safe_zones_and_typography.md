# Верстка экрана, Safe Zones и типографика для YouTube Shorts

Стандарт визуального оформления вертикальных роликов формата **1080x1920 (9:16)** для канала «Свободные Люди Запорожья».

---

## 1. Карта безопасных зон (Safe Zones)

Интерфейс мобильного приложения YouTube Shorts перекрывает верхнюю и нижнюю части экрана, а также правую колонку:
* **Сверху (Y = 0..160):** Строка поиска, стрелка «Назад», меню канала.
* **Снизу (Y = 1450..1920):** Название канала, кнопка «Подписаться», описание, название звуковой дорожки.
* **Справа (X = 920..1080):** Кнопки «Лайк», «Дизлайк», «Комментарии», «Поделиться», «Ремикс».

### Раскладка элементов в безопасной зоне:
```text
Y = 0       +---------------------------------------------+
            |  ВЕРХНЯЯ СЛЕПАЯ ЗОНА YOUTUBE (0..160)       |
Y = 170     +=============================================+
            |  ШАПКА ТЕМЫ (Y = 170..246, выс. 76px)       |  <-- Синяя/тёмная плашка
            +---------------------------------------------+
            |                                             |
Y = 430     |  +---------------------------------------+  |
            |  |  ЦЕНТРАЛЬНАЯ КАРТОЧКА ДОКУМЕНТА       |  |  <-- Ширина 920px, отступ 80px
            |  |  Цитата закона / судебного акта       |  |      Желтый маркер <mark>
            |  +---------------------------------------+  |
            |                                             |
            |  ЗОНА ДИНАМИЧЕСКИХ СУБТИТРОВ (.ass)         |
Y = 1350    |  (MarginV = 520, стиль Highlight)           |  <-- Выше описания и кнопок!
            |                                             |
Y = 1450    +=============================================+
            |  НИЖНЯЯ СЛЕПАЯ ЗОНА YOUTUBE (1450..1920)    |  <-- Текст сюда не заходит!
Y = 1920    +---------------------------------------------+
```

---

## 2. Параметры субтитров (.ass)

Для субтитров используется формат Advanced SubStation Alpha (.ass) с точным позиционированием:
* **Шрифт:** `DejaVu Sans Bold` / `Liberation Sans Bold`.
* **Размер:** 52–54 pt.
* **Цвет:** Белый с мягкой тенью и золотым караоке-выделением активного слова (`&H0000FFFF`).
* **Вертикальный отступ (`MarginV`):** строго **`520`** (не менее 480).
* **Длина реплики:** не более 22 символов (3–4 слова в строке), чтобы зритель успевал прочесть текст без пауз в видео.

---

## 3. Звуковой баланс и нормализация

* **Интегральная громкость:** ровно **−14.1 LUFS** (стандарт YouTube Shorts).
* **Истинный пик (True Peak):** не выше **−1.0 dBTP** (цель −1.3…−1.5 dBTP для защиты от клиппинга при сжатии YouTube).
* **Сайдчейн-дакинг:** фоновая музыка автоматически приглушается во время речи диктора на **13–15 дБ** (`sidechaincompress: threshold=0.04: ratio=5: attack=15: release=350`).
