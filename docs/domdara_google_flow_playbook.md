# Google Flow Automation & Impossible VFX Playbook

Руководство по автоматизации генерации видеоконтента через **Google Flow (Gemini Omni 1.1 Flash / Veo 3.1)** с помощью Chrome DevTools Protocol (CDP) и созданию невозможных спецэффектов (Impossible VFX).

---

## 1. Подключение и управление Chrome через CDP

Google Flow работает в авторизованной сессии пользователя Google Chrome:
```python
from playwright.sync_api import sync_playwright

browser = p.chromium.connect_over_cdp("http://localhost:9222")
page = browser.contexts[0].pages[0]
```

Запуск браузера с портом отладки:
```bash
google-chrome --remote-debugging-port=9222
```

---

## 2. Автоматическое конфигурирование режима видео

При открытии проекта Google Flow по умолчанию может активировать режим генерации изображений (*Nano Banana 2.1*). Конвейер автоматически:
1. Закрывает любые сервисные и обучающие модальные окна через селектор `button[aria-label="Закрыть сообщение"]`.
2. Кликает по селектору режима и активирует вкладку `[📹 Видео]`.
3. Устанавливает соотношение сторон **`9:16`** (вертикальный кадр).
4. Задаёт длительность сцены **`10 сек.`**.
5. Задаёт количество генераций за раз **`x1`**.
6. Закрывает диалог клавишей `Escape`.

## 3. Мастер-формула промптов «Невозможная камера» (Impossible VFX)

Обычная съёмка со штатива или дрона быстро теряет внимание зрителя в Shorts. Мы используем спецэффекты, которые физически невозможно снять камерой:

### Основные типы невозможных ракурсов:
1. **Стеклянный разрез (Aquarium Cross-Section):**  
   Камера прорезает поверхность океана или земли, показывая одновременно надводную часть (корабль в шторм) и подводную бездну (светящиеся косяки рыбы под лазерным лучом).
2. **Рентген волокон (Internal X-Ray Glide):**  
   Камера пролетает сквозь кору внутрь ствола векового дерева, где древесина становится прозрачным янтарём, а по капиллярам бегут био-нейронные импульсы.
3. **Обратная перемотка времени (LiDAR Time-Reverse):**  
   Лазерные кольца облака точек сканируют спиленный пень и материализуют живой дуб обратно из частиц.
4. **Морфинг препятствий (Energy Wave Morphing):**  
   Золотая волна энергии проходит вдоль берега реки, рассыпая бетонные заборы в искры и проращивая цветущие деревья с открытым песчаным пляжем.
5. **Символическое разрушение (Scale Shattering):**  
   Капля жидкого золотого света падает на чашу весов Фемиды, перевешивая огромную ржавую гирю монополиста и разрывая стальные цепи во вспышке искр.

### Обязательный хвост промпта:
```text
Vertical 9:16, 4k, photorealistic, clean composition, text-free, no labels, no watermarks, Unreal Engine 5 render style.
```

### Запреты:
- Полный запрет на генерацию крупных человеческих лиц и гуманоидных роботов (во избежание деформаций пальцев и неестественной мимики).
- Запрет на обратный ход времени в движении воды/дыма («пинг-понг» эффект) — монтаж выполняется строго вперёд.
