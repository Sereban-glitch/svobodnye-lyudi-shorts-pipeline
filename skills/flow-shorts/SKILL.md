# Шортс во Флоу (flow-shorts) — Автоматический конвейер YouTube Shorts

Эталонный конвейер полного цикла: от юридического/научного прецедента до генерации невозможных спецэффектов в Google Flow, синтеза дикторской речи и публикации в YouTube Shorts.

> **ЖЁСТКОЕ РАЗГРАНИЧЕНИЕ НАВЫКОВ:**
> * **`flow-shorts` («Шортс во Флоу»)** — **100% генерация с нуля**. Не требует видеоисходников владельца. Создаёт видео в Google Flow через Omni 1.1 Flash, верстает карточки документов, генерирует озвучку DmitryNeural.
> * **`video-montage`** — **только нарезка живого видео с камеры/телефона** (судебные заседания, стримы, архивные съемки).

## 1. Золотые правила конвейера

### 🎙️ 1.1. Голос (Audio-First и 100% DmitryNeural)
* **Разрешён ТОЛЬКО мужской дикторский голос:** `ru-RU-DmitryNeural` (Edge-TTS).
* **ПОЛНЫЙ ЗАПРЕТ на тихий фолбэк на женский Google TTS (`gTTS`).** При любых сбоях сети скрипт делает до 15 повторов с экспоненциальной паузой. Если Microsoft блокирует фразу — переформулировать слова (исключать триггеры спам-фильтров: *«долги»*, *«отстоять свои права»* заменять на нейтральные синонимы: *«вернуть свои средства»*, *«поделитесь мнением»*).
* **Сначала звук, потом видео:** Хронометраж каждой сцены определяется точной длиной дикторской фразы.

### 🎬 1.2. Визуальный ряд (Непрерывное движение вперёд)
* **ЗАПРЕТ на реверс («пинг-понг» / бумеранг):** Вода, дым, искры и движение камеры должны идти **строго и непрерывно вперёд**.
* **Подгонка длительности:** 
  - При `factor <= 1.90`: кинематографичный Slow-Mo вперёд (`setpts={factor}*PTS`). Выглядит как высокоскоростная съёмка National Geographic.
  - При `factor > 1.90`: склейка двух разных планов или прямой повтор вперёд без обратного хода.
  - При `raw > target`: обрезка (`trim=0:{target}`).

### 🌌 1.3. Формула промптов «Невозможная камера» (Impossible VFX)
Google Flow (Gemini Omni 1.1 Flash / Veo 3.1) способен на ракурсы, которые невозможно снять вживую:
1. **Стеклянный разрез:** Разрез океана, толщи воды или земли, показывающий одновременно поверхность и глубину.
2. **Рентген-пролёт:** Пролёт сквозь кору внутрь ствола дерева с видимыми светящимися импульсами по волокнам.
3. **Обратная перемотка времени (LiDAR):** Материализация живого дерева из спиленного пня по лазерным кольцам облака точек.
4. **Морфинг энергии:** Растворение бетонных стен и заборов в золотые частицы с прорастанием деревьев и открытием пляжа.
5. **Обязательные требования к промптам:**
   - Формат строго **Vertical 9:16**.
   - Полный запрет на крупные человеческие лица и гуманоидных роботов (чтобы избежать артефактов).
   - Обязательный хвост: `4k, photorealistic, clean composition, text-free, no labels, no watermarks`.

### 📱 1.4. Вёрстка и безопасные зоны (Safe Zones)
* **Кадр:** ровно 1080x1920, 30 fps.
* **Верхняя плашка:** заголовок темы на тёмной плашке (Y = 170..246).
* **Центральная карточка:** документ/закон с желтой подсветкой ключевой фразы `<mark>` (появляется во 2-й трети экрана).
* **Караоке-субтитры:** стиль Highlight, безопасный отступ снизу **`MarginV=520`** (зона выше кнопок лайков, комментариев и названия звука в YouTube Shorts).
* **Звук:** интегральная громкость ровно **−14.1 LUFS** (стандарт YouTube), пик <= −1.0 dBTP.
* **Фоновая музыка:** процедурный луп без резких ритмических ударов, сайдчейн-дакинг под голосом с разницей **13–15 дБ**.

## 2. Структура проекта ролика

Каждый ролик собирается в отдельной папке `projects/sh_[topic]_ru/`:
```text
projects/sh_[topic]_ru/
├── manifest.json            # Сценарий, промпты Flow, цитаты для карточек
├── pronunciation.json       # Ударения и замены для DmitryNeural
├── thumbnail.json           # Тексты и настройки обложки 1080x1920
├── config.json              # Привязка канала YouTube
├── cards/                   # Сгенерированные карточки документов (card_1..3.png)
├── source/                  # Исходные файлы:
│   ├── bg_1..4.mp4          # Ролики 720x1280 из Google Flow
│   ├── vo_1..4.wav          # Озвучка сцен (48 кГц stereo WAV)
│   ├── vo_full.wav          # Склеенная дикторская дорожка
│   ├── audio_timing.json    # Точные миллисекундные тайминги
│   ├── bgm_loop.wav         # Зацикленная фоновая подложка
│   └── base_video.mp4       # Склеенный видеоряд со Slow-Mo
├── subtitles.ass            # Субтитры в безопасной зоне
├── thumbnail.jpg            # Вертикальная обложка
└── final_short.mp4          # Финальный проверенный ролик
```

## 4. Чек-лист контроля качества (5 из 5 перед публикацией)

Скрипт `verify_short.py` автоматически проверяет 5 критериев:
1. **Контейнер:** 1080x1920, 30 fps, кодеки h264/aac, 48000 Hz, совпадение длительности видео и аудио с точностью до 0.1 с.
2. **Громкость:** ровно −14.0…−14.2 LUFS, истинный пик <= −1.0 dBTP.
3. **Баланс голоса и музыки:** музыка тише речи на 8–16 дБ (слышна в паузах, уходит под речь).
4. **Подложка:** отсутствие монотонных ударных ритмов (0 ударов).
5. **Субтитры:** безопасный вертикальный отступ `MarginV >= 480` (стандарт 520), 0 слишком длинных строк.
